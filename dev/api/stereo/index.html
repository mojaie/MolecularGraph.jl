MolecularGraph.safe_stereo_hydrogen! — Method
safe_stereo_hydrogen!(mol::SimpleMolGraph{T}, center::T) -> Union{T,Nothing}

Rearrange stereocenter properties to safely remove stereo hydrogen nodes and return the hydrogen node index (or nothing if there is no stereo hydrogen).

This function is called when stereocenters are obtained from SMILES or SDFile, so that hydrogen nodes can be safely removed while preserving stereocenter information (see also stereo_on_vertex_removal!).

stereo_on_edge_removal!(mol::SimpleMolGraph, e::Edge) -> Nothing

Remove the stereochemistry information invalidated by the removal of the edge e, with a warning: stereocenters at the ends of e, and stereobonds whose double bond is e or is connected to e.

MolecularGraph.stereo_on_vertex_removal! — Function
stereo_on_vertex_removal!(mol::SimpleMolGraph{T}, vs::Vector{T}) -> Nothing

Update the stereochemistry information before the removal of the vertices vs.

If hydrogens are removed, stereocenters and stereobonds referring to them are rewritten with the remaining neighbors (the chirality and the cis-trans configuration are preserved). If heavy atoms are removed, the stereocenters and stereobonds adjacent to them are removed with a warning. Stereochemistry at the removed vertices is removed without warning.

This is called inside rem_vertex! and rem_vertices!.

2D notation of stereocenters

Non-exported functions to keep 2D wedges consistent with the stereocenters.

MolecularGraph.assign_stereocenter_wedges! — Function
assign_stereocenter_wedges!(
    styles::Draw2dBondStyle, g::SimpleGraph{T}, v_symbol::Vector{Symbol},
    e_order::Vector{Int}, coords::Coords2d, centers::StereocenterMap{T}) where T -> Nothing
assign_stereocenter_wedges!(mol::SimpleMolGraph) -> Nothing

Update 2D bond styles (wedges) so that they represent the stereocenters.

The stereocenters (mol[:stereocenter]) are the reference of the stereochemistry, and the wedges are its 2D notation. For each stereocenter, if the wedges and the 2D coordinates do not represent the chirality (e.g. the wedges were on removed hydrogens, or the 2D coordinates were generated without wedges), the wedges starting at the center are replaced with a new wedge. Wedges that represent the chirality are kept as they are.

The new wedge is put on a single bond, preferably on an acyclic bond to a non-stereocenter terminal atom (e.g. hydrogen).

For ReactiveMolGraph, this is called automatically after the molecule is modified (see dispatch_update!) and in coordgen!.

Stereochemistry types

MolecularGraph.Stereocenter — Type
Stereocenter{T<:Integer}

Stereocenter (tetrahedral chirality) information.

Fields lookingFrom, first and second are neighbor vertices of the center. Looking from the lookingFrom vertex toward the center, first, second and the remaining neighbor (or the implicit hydrogen) are arranged clockwise if isclockwise is true, otherwise counterclockwise (the same convention as SMILES @@ and @). It can be converted to a tuple (lookingFrom, first, second, isclockwise).

See also set_stereocenter!.

source
MolecularGraph.StereocenterMap — Type
StereocenterMap{T<:Integer}

Mapping of the center vertex to Stereocenter (mol[:stereocenter]).

It behaves like a dictionary of T => Stereocenter{T}.

source
MolecularGraph.Stereobond — Type
Stereobond{T<:Integer}

Stereobond (cis-trans) information of a double bond.

first and second are the neighbors of the source and the destination vertex of the bond, respectively, and is_cis indicates whether they are on the same side of the double bond. It can be converted to a tuple (first, second, is_cis).

See also set_stereobond!.

source
MolecularGraph.StereobondMap — Type
StereobondMap{T<:Integer}

Mapping of the double bond (Edge{T}) to Stereobond (mol[:stereobond]).

It behaves like a dictionary of Edge{T} => Stereobond{T}.
