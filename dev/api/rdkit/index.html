RDKit interface

These functions require RDKitMinimalLib.jl to be loaded.

Note

RDKitMinimalLib.jl does not work on Windows currently: the RDKit library of RDKitjll for Windows does not export the functions of the RDKit C API (e.g. `could not load symbol "getmol"`).
