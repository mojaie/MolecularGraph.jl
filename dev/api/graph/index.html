maxcardmap(u, v, adj) -> Dict{Int,Int}

Return a maximum cardinality matching of the bipartite graph as a mapping of the nodes in u to the nodes in v.

Calculate maximum clique.

This is a molecular-mining-oriented variant of Graphs.maximum_clique: it accepts timeout and targetsize keyword arguments and reports a status alongside the result, both of which are needed in practice for the substructure-matching tasks in this package. The _mg suffix marks it as intentionally distinct from the like-named Graphs.jl function (#146).

MolecularGraph.ConstraintArrayMCES — Type
ConstraintArrayMCES{T,D,V,E}

Serializable constraints of a graph for maximum common edge-induced subgraph (MCES) calculation by maximum_common_subgraph.

Constraints are defined on the line graph, and the mapping of line graph vertices to the original edges and Δ-Y exchange information are also stored. See mces_constraints.

source
MolecularGraph.ConstraintArrayMCIS — Type
ConstraintArrayMCIS{T,D,V,E}

Serializable constraints of a graph for maximum common node-induced subgraph (MCIS) calculation by maximum_common_subgraph.

It has the node pairs, distances (or connections) between the paired nodes, and vertex/edge attributes for matching. See mcis_constraints.

MolecularGraph.VF2Matcher — Type
VF2Matcher{T,U}(g::SimpleGraph{T}, h::SimpleGraph{U}, matchtype::Symbol; kwargs...)

Lazy iterator that generate all isomorphism mappings between G and H.

matchtype should be one of the followings

  • :isomorphic: G is isomorphic to H
  • :subgraph_isomorphic: a node-induced subgraph of G is isomorphic to H
  • :monomorphic: a subgraph of G is monomorphic to H

Options

  • vmatch::Function: a function for semantic node attribute matching (default: (a, b) -> true)
  • ematch::Function: a function for semantic edge attribute matching (default: (a, b) -> true)
  • mandatory::Dict{T,U}: mandatory node mapping
  • forbidden::Dict{T,U}: forbidden node mapping
  • timeout::Union{Int,Nothing}: if specified, abort vf2 calculation when the time (in seconds) reached and return empty iterator (default: nothing, no timeout)

MolecularGraph.modular_product — Method
modular_product(g::SimpleGraph{T}, h::SimpleGraph{T};
    vmatch=(g1,h1)->true,
    edgefilter=(g1,g2,h1,h2)->has_edge(g,g1,g2)==has_edge(g,h1,h2)
) where T -> Tuple{SimpleGraph{T},Dict{Edge{T},Bool}}

Return the modular product m of graphs g and h, and a mapping whether the edge is connected or not. mapping g,h nodes to m nods is f(i, j) = (i - 1) * nv(h) + j and the reverse mapping is f(i) = (div(i - 1, nv(h)) + 1, mod(i - 1, nv(h))) + 1, where i in g and j in h.
