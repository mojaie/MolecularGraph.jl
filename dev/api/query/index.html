MolecularGraph.remove_hydrogens! — Method
remove_hydrogens!(qmol::QueryMolGraph) -> Nothing

Remove hydrogens from the molecular query.

Should be applied after specialize_nonaromatic!. This function is intended for generalization of PAINS query in PubChem dataset.

find_queries(mol::SimpleMolGraph, query_diagram; sources=[], filtering=true

Find query relationship diagram by the given molecule. The filtered diagram represents query relationship that the molecule have. Vertex records of the matched queries have "matched" (atom indices of the matches). The given query_diagram is not modified.
