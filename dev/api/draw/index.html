Molecular structure drawing

MolecularGraph.atom_radius — Method
atom_radius(mol::SimpleMolGraph; mapping=ATOM_VANDERWAALS_RADII) -> Vector{Float64}

Return atom radii of the molecule for 3D drawing.

mapping is a number (same radius for all atoms) or a mapping of atomic number to radius such as ATOM_VANDERWAALS_RADII and ATOM_COVALENT_RADII. If an element has multiple values (Dict{String,Float32}), the radius of carbon is chosen by hybridization ("Csp3", "Csp2" or "Csp") and the smallest one is chosen for the other elements.

ballstick(mol::MolGraph; radii=0.4, bonddiameter=0.1)

Represent mol as a ball-and-stick model in three dimensions. mol should have 3d atom positions in Angstroms. Requires loading a Makie backend (e.g. GLMakie or CairoMakie).
