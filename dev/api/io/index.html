MolecularGraph.sdfilereader — Method

Read SDFile data from input stream (or a file path as a string) and return a lazy iterator that yields molecule objects.

By default (unsupported=:log), sdfilereader does not stop and raise errors when an erroneous or incompatible SDFile block is read but produces an info message and yields an empty molecule. Use unsupported=:error to throw the error, or unsupported=:ignore to suppress the message.

JSON

Molecules can be serialized into JSON text by JSON.json(mol) and restored by mol_from_json. mol_from_json also reads RDKit CommonChem JSON.

JSON.json — Method
JSON.json(mol::ReactiveMolGraph) -> String

Serialize the molecule into JSON text. Molecules of SDFile, SMILES, SMARTS and CommonChem types are written by the concretely typed writer (compilable with juliac --trim).

source
MolecularGraph.mol_from_json — Function
mol_from_json(json::AbstractString; on_init=nothing, on_update=nothing) -> ReactiveMolGraph
mol_from_json(f, json::AbstractString; on_init=nothing, on_update=nothing)

Read a molecule from the JSON text (JSON.json(mol) output or RDKit CommonChem JSON). The molecule type is detected from the JSON.

The second form calls f(mol) and returns its result. mol has a concrete type in each branch of the type detection, so this form is compilable with juliac --trim (the return type of the first form cannot be inferred).

n = mol_from_json(json) do mol
    nv(mol)
end
