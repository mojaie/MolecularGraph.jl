MolecularGraph.jl

MolecularGraph.jl is a graph-based molecule modeling and chemoinformatics analysis toolkit fully implemented in Julia.

README.md on GitHub

Installation

pkg> add MolecularGraph

Usage

  • Getting Started: read molecules, draw structures, calculate properties and search substructures
  • Basics
    • Concept of molecular graph models: scope, graph operations, atom and bond properties
    • Core functions
    • Properties and descriptors: built-in properties and the auto-update mechanism
    • Drawing molecules: 2D structure images (SVG/PNG), 2D coordinates and 3D rendering
    • Preprocessing: hydrogens, components, charges, resonance structures and custom updaters
    • Stereochemistry
    • Mass and isotopes: molecular weight, exact mass, isotopic composition and mass spectra
    • Substructure and query: substructure match, InChI, SMARTS queries and structural alerts
    • Maximum common substructure: MCIS, MCES and topological constraints (tdMCS)
  • Advanced topics
    • MolecularGraph interfaces
    • Customize atom and bond properties

Interactive Pluto.jl notebook tutorials are also available (some of them are based on older versions).
