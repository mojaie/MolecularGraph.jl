Coordinates

MolecularGraph.coordgen! — Method
coordgen!(mol::SimpleMolGraph)

Generate 2D coordinates by coordgen and store them (and the wedge notation styles) in the descriptors of mol, replacing existing 2D coordinates.

source
MolecularGraph.coordgen — Method
coordgen(mol::SimpleMolGraph) -> Tuple{Coords2d,Draw2dBondStyle}

Generate 2D coordinates by using Schrodinger's coordgenlibs.

This will returns a tuple of coords and styles. coords stores 2D coordinates (x, y) of each atom as Point2d. styles stores the wedge notation of each bond as a Symbol (:none, :up, :down, :revup or :revdown). Wedges of stereocenters that are not displayed by coordgenlibs are complemented by assign_stereocenter_wedges!.

source
MolecularGraph.coords2d — Method
coords2d(mol::SimpleMolGraph, i::Integer=1) -> Coords2d

Return the ith set of 2D coordinates of the molecule.

Throws an error if the molecule type does not support 2D coordinates or the coordinates are not available (run coordgen! to generate them). See also has_coords2d.

MolecularGraph.coords_from_sdf! — Method
coords_from_sdf!(mol::SimpleMolGraph) -> Nothing

Set 2D coordinates, 3D coordinates (if the z coordinates are not all zero) and 2D bond styles (wedges) to the molecule descriptors from the coords field of the atoms and the notation field of the bonds (e.g. SDFAtom and SDFBond).

This function is called in sdf_on_init! before stereochemistry initializers.

source

MolecularGraph.update_coords! — Method
update_coords!(mol::SimpleMolGraph) -> Nothing

Discard the current coordinates and 2D bond styles and recalculate them.

If the atom type has the coords field and all atoms have coordinates, they are taken from the atoms by coords_from_sdf!. Otherwise, 2D coordinates are generated by coordgen!.

Coordinate types

MolecularGraph.Coords2d — Type
Coords2d

A set of 2D coordinates (Point2d) of the atoms. It behaves like a vector of Point2d.
