MolecularGraph.MolGraph — Type
MolGraph{T,V,E} <: ReactiveMolGraph{T,V,E}

Basic molecular graph type.

Usually MolGraphs are not directly constructed, but constructed by molecule reader methods such as smilestomol or sdfilereader. Atom and Bond properties of MolGraph are specific to the type of morecular reader (e.g. sdfilereader generates MolGraph{Int,SDFAtom,SDFBond} instances).

MolecularGraph.add_u_edge! — Function
add_u_edge!(mol::ReactiveMolGraph, e::Edge, prop::AbstractElement) -> Bool

Add undirected edge to the ReactiveMolGraph and notifies the update to updator functions.

This is called internally by the API function add_edge!(mol, e, prop). add_edge!(mol, e, prop) always add the sorted edge to the undirected molecular graph. add_u_edge! can be directly called if src < dst is guaranteed.

source
MolecularGraph.rem_u_edge! — Function
rem_u_edge!(mol::ReactiveMolGraph, e::Edge) -> Bool

Remove undirected edge to the ReactiveMolGraph and notifies the update to updator functions.

This is called internally by the API function rem_edge!(mol, e). rem_edge!(mol, e) always remove the sorted edge from the undirected molecular graph. rem_u_edge! can be directly called if src < dst is guaranteed.

If the edge is connected to a stereocenter or a stereobond (double bond), the stereochemistry information is removed with a warning (see stereo_on_edge_removal!).

source
MolecularGraph.ReactiveMolGraph — Type
ReactiveMolGraph{T<:Integer,V<:AbstractElement,E<:AbstractElement} <: SimpleMolGraph{T}

The base class of molecule model which have auto-update mechanism of properties.

Typically ReactiveMolGraph should have the following properties:

  • graph: molecular graph topology in Graphs.SimpleGraph.
  • vprops: Dict of atom properties (e.g. SDFAtom, SMILESAtom) keyed by vertex
  • eprops: Dict of bond properties (e.g. SDFBond, SMILESBond) keyed by edge
  • gprops: graph-level properties and stored descriptors (e.g. stereocenter)
  • state: update flags and callback functions for reactive property update

MolecularGraph.MolState — Type
MolState{T,F1,F2} <: AbstractState

The state container for ReactiveMolGraph.

on_init::F1 and on_update::F2 are callbacks for descriptor initialization and update. Their types are part of the state type so that the callbacks are statically dispatched (required for juliac --trim). The callbacks are fixed at construction; to replace them, create a new molecule by MolecularGraph.with_callbacks.

source
MolecularGraph.dispatch_update! — Function
dispatch_update!(mol::ReactiveMolGraph) -> Nothing

Dispatch property auto-update mechanisms.

This is called by functions that returns calculated properties (descriptors). If the vertices or edges has been added or removed, onupdate callback is triggered to recalculate descriptors, and then 2D wedges are updated to represent the stereocenters ([`assignstereocenter_wedges!`](@ref)). If there are no changes, do nothing.

MolecularGraph.notify_new_edges! — Function
notify_new_edges!(mol::ReactiveMolGraph) -> Nothing

Set :has_new_edges flag to inform property updaters that recalculation is required.

This mechanism is similar to notify_updates!, but is specific to the add_edge! and rem_edge! methods. Unlike other descriptors, the sssr descriptor does not require recalculation when vertices are removed or added — remapping is sufficient in those cases. Therefore, the :has_new_edges flag is used to avoid unnecessary and costly minimum cycle recalculation.
